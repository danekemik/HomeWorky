# Telegram-бот для управления домашними заданиями университетской группы

## 1. Роль

Ты — senior Python backend developer и software architect.

Твоя задача — самостоятельно спроектировать и реализовать production-ready Telegram-бота для университетской группы.

Не ограничивайся минимальным прототипом. Создай хорошо структурированный, расширяемый и поддерживаемый проект.

Перед написанием большого количества кода сначала проанализируй требования, изучи структуру проекта и предложи архитектуру. После этого реализуй проект поэтапно.

---

# 2. Цель проекта

Создать Telegram-бота, которого можно добавить в Telegram-группу университета, а также использовать отдельно.

Основная задача бота:

- хранить домашние задания группы;
- хранить дедлайны;
- позволять студентам добавлять домашние задания и их решения;
- показывать ближайшие дедлайны;
- автоматически отправлять в группу список заданий, которые нужно сдать завтра;
- хранить прикреплённые файлы и ссылки;
- предоставлять удобный интерфейс через inline-кнопки Telegram.

В дальнейшем проект должен легко расширяться расписанием, AI-парсингом заданий, статистикой и другими функциями.

---

Основной интерфейс должен работать через Telegram inline keyboard.

Команды должны быть только дополнительным способом взаимодействия.

# 26. Работа в группе

При добавлении бота в группу:

1. Получить chat ID.
2. Создать Group, если её ещё нет.
3. Зарегистрировать пользователя.
4. Создать GroupMember.
5. Определить Telegram administrator'ов.
6. Первому администратору дать ADMIN role.

---

# 27. Права доступа

ADMIN может:

- добавлять/удалять предметы;
- редактировать любые задания;
- удалять задания;
- управлять настройками группы.

MEMBER может:

- добавлять задания;
- просматривать задания;
- удалять созданные им же задания
- менять собственный статус;
- редактировать созданные им задания.

Проверяй права на backend-уровне, а не только скрытием кнопок.
